# Lab 03 - Task 2: Online Shopping Cart

## Objective

Implement shopping cart behavior using ES6 logic for item management, totals, and rendering.

## Files

- `index.html`
- `style.css`
- `script.js`

## Implementation Highlights

- Cart data structures using arrays and objects
- Add/remove quantity operations
- Dynamic subtotal/total calculations
- Reactive UI rendering through DOM manipulation

## How to Run

1. Open `index.html` in a browser.
2. Interact with cart actions and verify totals.
