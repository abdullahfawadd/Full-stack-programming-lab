# Lab 03 - Task 7: Student Data with JSON

## Objective

Work with JSON-formatted student data and render it into a readable UI using ES6 JavaScript.

## Files

- `index.html`
- `style.css`
- `script.js`

## Implementation Highlights

- JSON parsing and object transformation
- Data iteration with modern JavaScript methods
- Structured output rendering in the DOM
- Clean separation between data and presentation logic

## How to Run

1. Open `index.html` in a browser.
2. Load/render the student dataset and inspect results.
