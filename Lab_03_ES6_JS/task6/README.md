# Lab 03 - Task 6: Mini University Portal

## Objective

Combine multiple entities and workflows into a mini portal to practice modular front-end architecture.

## Files

- `index.html`
- `style.css`
- `script.js`

## Implementation Highlights

- Multi-entity data handling (students/courses/records)
- Structured module-style JavaScript logic
- Screen-level UI sections for clearer workflow
- Dynamic updates based on user interaction

## How to Run

1. Open `index.html` in a browser.
2. Use available controls to navigate portal features.
