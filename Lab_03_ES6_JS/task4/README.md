# Lab 03 - Task 4: Course Registration System

## Objective

Create a registration workflow that maps students to courses while enforcing simple validation constraints.

## Files

- `index.html`
- `style.css`
- `script.js`

## Implementation Highlights

- Course and registration data modeling
- Validation of user input before enrollment
- Dynamic registration list updates
- Structured UI feedback for user actions

## How to Run

1. Open `index.html` in a browser.
2. Submit course registration actions and review updates.
