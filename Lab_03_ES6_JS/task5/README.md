# Lab 03 - Task 5: Product Catalog

## Objective

Develop a product catalog interface with ES6-driven rendering and client-side data operations.

## Files

- `index.html`
- `style.css`
- `script.js`

## Implementation Highlights

- Product dataset rendering into structured cards/list
- Filtering or sorting style operations
- Reusable display functions for maintainability
- DOM updates tied to user controls

## How to Run

1. Open `index.html` in a browser.
2. Interact with catalog controls and inspect output.
