# Lab 03 - Task 1: Student Management System

## Objective

Build an ES6-based student record manager to practice object handling, array operations, and dynamic UI updates.

## Files

- `index.html`
- `style.css`
- `script.js`

## Implementation Highlights

- Student data modeled with JavaScript objects
- Add/update/display workflow for records
- List rendering through reusable functions
- Interactive feedback with DOM updates

## How to Run

1. Open `index.html` in a browser.
2. Add or manage student entries through the UI.
