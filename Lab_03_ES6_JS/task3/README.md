# Lab 03 - Task 3: Asynchronous Data Loader

## Objective

Practice asynchronous JavaScript by loading and displaying remote or delayed data with user feedback states.

## Files

- `index.html`
- `style.css`
- `script.js`

## Implementation Highlights

- Async data flow using modern JavaScript patterns
- Loading and completion states in the UI
- Error-safe rendering pathway
- Separation between data-fetching and view-update logic

## How to Run

1. Open `index.html` in a browser.
2. Trigger data load and observe async behavior.
