# Lab 08 - Task 1: Multi-Page Next.js App

## Objective

Implement a professional multi-page Next.js application with reusable global layout components.

## Required Pages

- Home (`/home`)
- About (`/about`)
- Contact (`/contact`)

## Layout Requirements

- Global Header component with route navigation
- Global Footer included via `layout.tsx`
- Consistent style system across all pages

## Relevant Source

- `src/app/layout.tsx`
- `src/components/Header.tsx`
- `src/components/Footer.tsx`
- `src/app/home/page.tsx`
- `src/app/about/page.tsx`
- `src/app/contact/page.tsx`

## Notes

This task is integrated into a dashboard-first architecture where `/` routes users into task modules.
