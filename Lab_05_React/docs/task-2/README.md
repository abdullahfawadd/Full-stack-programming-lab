# Lab 05 - Task 2: Course List App

## Objective

Render a list of courses using reusable components and array mapping in React.

## Route

- `/task2`

## Relevant Source

- `src/pages/CourseListApp.jsx`
- `src/components/CourseItem.jsx`

## Implementation Highlights

- Dynamic list rendering with `.map()`
- Reusable course card component
- Props-based data display
- Optional type/status badge styling

## Run

From `Lab_05_React`:

```bash
npm install
npm run dev
```
