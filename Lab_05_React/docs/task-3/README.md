# Lab 05 - Task 3: Dynamic Greeting App

## Objective

Use props and conditional rendering to display context-aware greeting cards.

## Route

- `/task3`

## Relevant Source

- `src/pages/GreetingApp.jsx`
- `src/components/Greeting.jsx`

## Implementation Highlights

- Greeting message selected by `timeOfDay`
- Reusable presentation component with props
- Conditional visual styling based on context
- Multiple rendered variations to demonstrate reusability

## Run

From `Lab_05_React`:

```bash
npm install
npm run dev
```
