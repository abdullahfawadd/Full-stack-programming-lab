# Lab 05 - Task 1: Student Information Card App

## Objective

Create reusable React card components to display student profiles via props.

## Route

- `/task1`

## Relevant Source

- `src/pages/StudentCardApp.jsx`
- `src/components/StudentCard.jsx`

## Implementation Highlights

- Reusable `StudentCard` component
- Prop-driven content rendering
- Multiple card instances from structured data
- Visual consistency through shared component CSS

## Run

From `Lab_05_React`:

```bash
npm install
npm run dev
```
