# Lab 02 - Task 2: Interactive Calculator

## Objective

Develop a simple calculator that handles four arithmetic operations with input validation and user-friendly result presentation.

## Files

- `index.html`
- `style.css`
- `script.js`

## Implementation Highlights

- Two numeric input fields and operation selector
- Event-driven calculate and reset controls
- Validation for empty, invalid, and divide-by-zero cases
- Dynamic result rendering in the DOM
- UI feedback that reflects output state

## How to Run

1. Open `index.html` in a browser.
2. Enter values and choose an operation.
3. Click calculate to view the result.
