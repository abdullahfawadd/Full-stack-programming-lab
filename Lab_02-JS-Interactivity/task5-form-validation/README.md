# Lab 02 - Task 5: Form Validation

## Objective

Design a registration form with field-level validation and real-time feedback for better input quality.

## Files

- `index.html`
- `style.css`
- `script.js`

## Implementation Highlights

- Validation rules for name, email, age, and password
- Error messaging for invalid field states
- Success pathway for valid submissions
- Confirmation and browser dialog integration for interaction flow
- DOM-driven updates without page reload

## How to Run

1. Open `index.html` in a browser.
2. Fill the form and submit.
3. Resolve validation errors until successful submission.
