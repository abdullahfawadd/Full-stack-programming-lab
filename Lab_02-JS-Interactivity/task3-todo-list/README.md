# Lab 02 - Task 3: Simple To-Do List

## Objective

Implement a basic task list manager with add, complete, remove, and reset interactions.

## Files

- `index.html`
- `style.css`
- `script.js`

## Implementation Highlights

- Input-driven task creation
- DOM updates for task insertion and state changes
- Completion toggle with visual status update
- Task removal controls
- Reset action to clear all task entries

## How to Run

1. Open `index.html` in a browser.
2. Add tasks and manage their state.
3. Use reset to clear all data.
