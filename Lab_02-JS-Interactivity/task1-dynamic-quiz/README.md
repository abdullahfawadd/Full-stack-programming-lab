# Lab 02 - Task 1: Dynamic Quiz

## Objective

Build a browser-based quiz interface that evaluates multiple-choice responses and provides immediate performance feedback.

## Files

- `index.html`
- `style.css`
- `script.js`

## Implementation Highlights

- Multi-question quiz rendered through structured markup
- JavaScript validation logic for answer selection
- Dynamic score calculation and result output
- Conditional feedback messaging based on final score
- Reset flow to clear user selections and restart the quiz

## How to Run

1. Open `index.html` in a browser.
2. Select answers and submit the quiz.
3. Review score and feedback.
