# Lab 02 - Task 4: Color Box Generator

## Objective

Create a color utility that generates visual color cards from user input and demonstrates DOM/BOM interaction.

## Files

- `index.html`
- `style.css`
- `script.js`

## Implementation Highlights

- User-provided color values (hex, rgb, named colors)
- Dynamic creation of color preview boxes
- Grid-based rendering of generated elements
- Clear-all action for quick reset
- Browser and viewport information display using BOM values

## How to Run

1. Open `index.html` in a browser.
2. Enter color values and generate boxes.
3. Clear the board when needed.
