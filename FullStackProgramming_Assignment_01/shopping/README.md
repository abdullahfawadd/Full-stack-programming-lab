# Assignment 01: Shopping Module

Shopping module pages for cart, checkout, and policy communication in Assignment 01.

## Included Pages

- `cart.html` Cart management and item summary
- `payment.html` Checkout/payment workflow
- `terms.html` Terms and conditions page

## Objectives

- Support a clear purchase flow from cart to checkout
- Present billing and payment details in a structured format
- Ensure users can access terms before final submission

## Run Instructions

Open each page directly in a browser:

- `cart.html`
- `payment.html`
- `terms.html`
