# Assignment 01: Profile Module

Profile module pages for account editing and order history in Assignment 01.

## Included Pages

- `edit-account.html` Profile information editing
- `order-summary.html` User order list and summaries
- `order-details.html` Detailed order breakdown

## Objectives

- Provide user-centric account management workflows
- Present order data with clear visual hierarchy
- Keep profile interactions consistent with assignment UI

## Run Instructions

Open each page directly in a browser:

- `edit-account.html`
- `order-summary.html`
- `order-details.html`
