# Lab 06 React JS App 
 
Fresh Lab 06 implementation for the Full Stack Programming Lab, built with React and Vite. 
 
## Included Tasks 
 
1. Counter Application 
2. User Form App 
3. Interactive Buttons App 
4. Multi-Page Website with React Router 
 
## Structure 
 
- src/components - shared shell and task layout 
- src/data - dashboard task metadata 
- src/features/counter-app - task 1 
- src/features/user-form-app - task 2 
- src/features/event-app - task 3 
- src/features/routing-app - task 4 
- src/pages - dashboard and global 404 
 
## Run 
 
npm install 
npm run dev 
npm run build
