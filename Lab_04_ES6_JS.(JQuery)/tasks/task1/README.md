# Lab 04 - Task 1: Dynamic List Manager

## Objective

Implement a jQuery-powered list manager with interactive item creation and removal workflows.

## Files

- `index.html`
- `task1.css`
- `task1.js`

## Implementation Highlights

- jQuery event handling for add/remove actions
- Dynamic DOM insertion for list items
- Input validation before item creation
- Smooth UI behavior for list updates

## How to Run

1. Open `index.html` in a browser.
2. Add and manage list entries.
