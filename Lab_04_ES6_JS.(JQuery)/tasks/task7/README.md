# Lab 04 - Task 7: Drag-and-Drop Sortable List

## Objective

Implement reorderable list behavior with drag-and-drop interactions.

## Files

- `index.html`
- `task7.css`
- `task7.js`

## Implementation Highlights

- Drag-and-drop enabled list items
- Sort order updates through user gestures
- Visual cues for drag state and drop targets
- jQuery event handling for interaction lifecycle

## How to Run

1. Open `index.html` in a browser.
2. Drag list items to reorder positions.
