# Lab 04 - Task 3: Interactive Form Validation

## Objective

Build a jQuery-based validation workflow with immediate feedback and controlled submission.

## Files

- `index.html`
- `task3.css`
- `task3.js`

## Implementation Highlights

- Field-level validation logic
- Inline error and success indicators
- jQuery-based event binding and handling
- Submission gating until valid input state

## How to Run

1. Open `index.html` in a browser.
2. Submit the form and review validation behavior.
