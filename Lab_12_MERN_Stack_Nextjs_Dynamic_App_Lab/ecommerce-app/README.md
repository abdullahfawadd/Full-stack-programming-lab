# Rustik Studio

Production-style MERN ecommerce application for Lab 12 with a clean Rustik plant and home-goods storefront.

## Student

- Name: M Abdullah
- Database: `lab12_dynamic_ecommerce`
- Collection: `products`

## Applications

- `backend`: Node.js, Express, MongoDB, Mongoose
- `frontend`: Next.js, TypeScript, Tailwind CSS

## Quick Start

Start local MongoDB first, then run:

```bash
cd backend
npm install
npm run seed
npm run dev
```

In another terminal:

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:3000`.

## Backend URL

```text
http://localhost:5000
```

## API

- `GET /api/products`
- `GET /api/products/:id`
- `POST /api/products`
- `PUT /api/products/:id`
- `PATCH /api/products/:id`
- `DELETE /api/products/:id`
