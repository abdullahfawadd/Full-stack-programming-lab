# Rustik Studio Frontend

Next.js App Router frontend for the Lab 12 dynamic ecommerce app.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run lint
npm run build
npm run start
```

The frontend expects the backend API at `http://localhost:5000/api`. Override with `NEXT_PUBLIC_API_URL` if needed.
