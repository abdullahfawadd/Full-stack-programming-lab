# Commerce Studio

A production-style MERN ecommerce application with a modular Express API and a premium Next.js catalog frontend.

## Applications

- `backend`: Node.js, Express, MongoDB, Mongoose
- `frontend`: Next.js, TypeScript, Tailwind CSS, Axios

## Quick Start

Start local MongoDB first, then run:

```bash
cd backend
npm install
npm run seed
npm run dev
```

In another terminal:

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:3000`.

## Backend URL

```text
http://localhost:5000
```

## API

- `GET /api/products`
- `GET /api/products/:id`
- `POST /api/products`
